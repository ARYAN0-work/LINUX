# Chapter 13 Summary

| Command | Purpose |
|---------|---------|
| `paste` | Combines fields from different files. |
| `join` | Combines lines from two files. |
| `split` | Splits a large file into smaller files. |
| `grep` | Searches text using patterns (regex). |
| `tr` | Translates, deletes, or squeezes characters. |
| `strings` | Extracts readable text from binary files. |
| `tee` | Displays output and saves it to a file. |
| `wc` | Counts lines, words, bytes, and characters. |
