# Chapter 11 Summary – Text Editors

## Creating & Editing Files

Linux provides both **terminal-based** and **graphical** text editors for creating and editing files.

---

## Common Text Editors

### Nano
- Beginner-friendly terminal editor
- Simple and easy to use

### Gedit
- Graphical text editor
- Similar to Windows Notepad

### Vi / Vim
- Powerful terminal editor
- Fast and widely used by system administrators

### Emacs
- Highly customizable text editor
- Used for programming and advanced editing

---

## Key Takeaways

- Linux supports both **CLI** and **GUI** text editors.
- **Nano** is best for beginners.
- **Gedit** is a simple graphical editor.
- **Vi/Vim** is the most common professional terminal editor.
- **Emacs** is a powerful, feature-rich editor.
