# Additional `/proc` Directories

Besides the common information files, the `/proc` filesystem also contains several important subdirectories.

---

## `/proc/<PID>`

Every running process on the system has its own directory inside `/proc`.

The directory name is simply the **Process ID (PID)**.

Example:

```text
/proc/1
/proc/2435
/proc/9876
```

Inside each process directory you can find information such as:

- Command used to start the process
- Environment variables
- Open file descriptors
- Memory usage
- Current working directory
- Process status

Example:

```bash
ls /proc/1234
cat /proc/1234/status
```

---

## `/proc/sys`

The `/proc/sys` directory contains **kernel configuration parameters**.

These values can be viewed or modified at runtime without rebooting the system.

Examples:

```text
/proc/sys/kernel/
/proc/sys/net/
/proc/sys/fs/
/proc/sys/vm/
```

Example:

```bash
cat /proc/sys/kernel/hostname
```

Change a value (requires root):

```bash
echo new-hostname | sudo tee /proc/sys/kernel/hostname
```

---

## Summary

- `/proc/<PID>` → Information about a specific running process.
- `/proc/sys` → Runtime kernel configuration parameters.
- `/proc` is a virtual filesystem generated by the Linux kernel.
- It provides system, hardware, kernel, and process information without storing actual files on disk.
