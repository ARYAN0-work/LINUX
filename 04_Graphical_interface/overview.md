## Core Topics Covered

Based on the course curriculum, this repository currently tracks the following modules:

*   **GUI Management**
    *   Managing graphical interfaces
    *   Performing day-to-day operations using the GUI
    *   Changing and configuring graphical desktops (Ubuntu/GNOME setups)
*   **Command Line Interface (CLI)**
    *   Essential Linux commands
    *   File system navigation and permissions
    *   Package management and system administration basics
