# Basic Linux Commands

These are the most commonly used Linux commands. Every Linux user, Backend Developer, and DevOps Engineer should know them.

| Command | Purpose | Example |
|---------|---------|---------|
| `cd` | Change the current directory | `cd Documents` |
| `ls` | List files and directories | `ls -la` |
| `mkdir` | Create a new directory | `mkdir project` |
| `rmdir` | Remove an empty directory | `rmdir project` |
| `cat` | Display or combine file contents | `cat file.txt` |
| `echo` | Print text or write to a file | `echo "Hello"` |
| `man` | Show the manual page for a command | `man ls` |
| `login` | Log into the Linux system | `login username` |
| `exit` | Exit the current shell or terminal | `exit` |
