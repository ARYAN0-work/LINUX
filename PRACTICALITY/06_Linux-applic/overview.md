# What matters for you 🟢

These are the applications/tools you should actually know:

- Git → version control
- VS Code / Vim / Nano → editing code
- Node.js → run your backend
- Docker → containers
- Python → scripting/automation
- GCC/G++ → compile C/C++
- GDB → debugging
- Browser → testing web apps

For your backend path, the important ones are:

Linux
 ├── Terminal
 ├── Git
 ├── Node.js
 ├── Docker
 ├── VS Code/Vim
 └── networking tools
Package installation

```bash
You've already learned this:

Ubuntu:

sudo apt update
sudo apt install <package>

Fedora:

sudo dnf install <package>

Arch:

sudo pacman -S <package>

You don't need to install Firefox, LibreOffice, GIMP, VLC, etc. just because they're in the notes.
```

# Priority

🟢 Learn/use: Git, Node.js, Docker, terminal tools, editor
🟡 Know: package managers and how applications are installed
🔴 Skip: Office suites, multimedia apps, graphics editors, email/FTP clients
