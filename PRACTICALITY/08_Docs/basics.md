🟢 Must know
man — full manual
man ls
man cp
man mkdir

Use it when you want detailed information about a command.

You already practiced this.

--help — quick help
ls --help
cp --help
grep --help

Good when you just need to remember options/syntax quickly.

help — Bash built-ins
help cd
help echo

Use this for commands that are built into Bash.

🟡 Know exists
info
info bash

More detailed/structured documentation.

You don't need to study info deeply right now.

/usr/share/doc/
/usr/share/doc/

Contains documentation for installed packages.

Just know it exists.
