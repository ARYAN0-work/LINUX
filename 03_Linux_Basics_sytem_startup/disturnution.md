# Linux Distributions

Linux is **not one operating system**.

The **Linux Kernel** is the core.

Different companies and communities build complete operating systems around the kernel. These are called **Linux Distributions (Distros).**

```
Linux Kernel
      │
      ├── Server Distros
      │      ├── RHEL (Red Hat Enterprise Linux)
      │      ├── CentOS
      │      ├── Ubuntu Server
      │      └── SUSE (SLES)
      │
      ├── Desktop Distros
      │      ├── Ubuntu
      │      ├── Fedora
      │      ├── Linux Mint
      │      └── Debian
      │
      └── Embedded Distros
             ├── Yocto
             ├── OpenEmbedded
             └── Android
```

---

## What is a Linux Distribution?

A Linux Distribution (Distro) is:

- Linux Kernel
- System libraries
- Package manager
- Command-line tools
- Desktop environment (optional)
- Applications

Together these create a complete operating system.

Example:

Ubuntu =
Linux Kernel +
GNOME +
APT Package Manager +
GNU utilities +
Ubuntu tools

---

## Categories of Linux Distributions

### 1. Server

Used for:

- Web servers
- Cloud
- Databases
- Containers

Examples:

- Ubuntu Server
- RHEL
- CentOS
- SLES

Usually no graphical interface is installed.

---

### 2. Desktop

Used on personal computers.

Examples:

- Ubuntu
- Fedora
- Linux Mint
- Debian

Provides a graphical desktop environment.

---

### 3. Embedded

Used in:

- Cars
- TVs
- Routers
- Smart devices
- IoT devices

Examples:

- Yocto
- OpenEmbedded
- Android (uses the Linux kernel)

---

## In Simple Words

Think of the **Linux Kernel** as an engine.

Different companies build different vehicles around that engine.

```
Engine
   │
   ├── Car (Ubuntu)
   ├── Truck (Ubuntu Server)
   ├── Sports Car (Fedora)
   └── Bike (Android)
```

They all use the same engine but are built for different purposes.

---

## Important

Ubuntu Desktop ≠ Ubuntu Server

Both use the same Linux kernel.

The difference is:

- Installed software
- GUI or no GUI
- Default packages
- Target use case
