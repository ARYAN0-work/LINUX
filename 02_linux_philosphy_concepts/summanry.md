# Chapter 2 Summary

## Linux Philosophy and Concepts

- Linux is heavily inspired by **UNIX** and follows many of the same design principles.

- In Linux, **everything is treated as a file**, allowing a consistent way to access hardware, devices, and system resources.

- Linux is a **multiuser** and **multitasking** operating system, allowing multiple users and multiple processes to run simultaneously.

- Understanding core Linux terminology is essential:
  - Kernel
  - Distribution
  - Boot Loader
  - Service
  - Filesystem
  - X Window System
  - Desktop Environment
  - Command Line
- A **Linux Distribution (Distro)** is a complete operating system that combines the **Linux Kernel** with system tools, libraries, package managers, and applications.
