# Chapter 12 Summary

- Linux is a **multi-user operating system**.
- `who` → Show logged-in users.
- `whoami` → Show current user.
- `root` has full system privileges.
- `sudo` gives temporary root access.
- Startup files configure the user environment.
- Environment variables store system/application settings.
- `history` displays previously executed commands.
- Keyboard shortcuts improve terminal productivity.
- `alias` creates custom command shortcuts.
- `chmod` changes file permissions.
- `chown` changes file ownership.
- `chgrp` changes file group ownership.
