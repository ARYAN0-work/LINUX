# Chapter 14 - Networking Operations

## Overview

This chapter introduces the fundamentals of networking in Linux. You'll learn how devices communicate over a network, configure network interfaces, use common networking utilities, browse the web from both graphical and command-line tools, and transfer files between local and remote systems. It also covers the basics of enabling communication and file sharing between devices.

## Topics Covered

- Understand basic networking concepts.
- Configure network interfaces.
- Use common networking utilities.
- Browse the web using GUI and terminal-based browsers.
- Transfer files between local and remote systems.
- Enable communication between devices.
- Configure basic file sharing.
