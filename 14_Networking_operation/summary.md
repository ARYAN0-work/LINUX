# Networking Summary

- Every device on a network has a unique **IP address**.
- **IPv4** uses **32 bits**; **IPv6** uses **128 bits**.
- An IP address consists of **network** and **host** portions.
- IPv4 addresses are divided into **five classes (A–E)**.
- **DNS** translates domain names into IP addresses.
- `ifconfig` displays network interface information (legacy).
- `ip addr show` displays IP addresses and interfaces.
- `ip route show` displays the routing table.
- `ping` checks whether a remote host is reachable.
- `route` manages the system routing table (legacy).
- Networking tools help diagnose and troubleshoot network problems.
- Common graphical browsers include **Firefox**, **Chrome**, **Chromium**, and **Epiphany**.
- Common text-based browsers include **Lynx**, **Links**, and **w3m**.
- `wget` downloads files or web pages from the internet.
- `curl` retrieves or sends data to URLs and APIs.
- **SSH** provides secure remote login and command execution.
- **SCP** securely copies files between systems over SSH.
- Two Linux machines can communicate securely using **SSH** and **SCP**.
