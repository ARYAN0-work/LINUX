# Text-Based Web Browsers

Linux also provides **text-based (non-graphical) web browsers** that run entirely in the terminal. They are useful on servers, low-resource systems, or when no graphical interface is available.

---

# `lynx`

`lynx` is one of the oldest and most widely used text-based web browsers.

### Features

- Runs entirely in the terminal
- Lightweight and fast
- Keyboard-driven navigation
- Still actively available on many Linux systems

---

# `elinks`

`elinks` is an enhanced version of Lynx with additional capabilities.

### Features

- Supports tables and frames
- Better navigation
- Improved user interface
- More configurable than Lynx

---

# `w3m`

`w3m` is another powerful terminal-based web browser.

### Features

- Fast and lightweight
- Supports tables
- Many advanced browsing features
- Can display images in supported terminal environments

---

# Common Installation

```bash
sudo apt install lynx
sudo apt install elinks
sudo apt install w3m
```

---

# Comparison

| Browser | Description |
|---------|-------------|
| `lynx` | Classic text-based browser; lightweight and reliable. |
| `elinks` | Enhanced Lynx with support for tables and frames. |
| `w3m` | Feature-rich text browser with optional image support. |

---

# When to Use

- Browsing on remote Linux servers
- Systems without a graphical desktop
- Low-memory environments
- Quick documentation lookup from the terminal
- SSH sessions

---

# Summary

- `lynx`, `elinks`, and `w3m` are terminal-based web browsers.
- They allow web browsing without a graphical interface.
- These browsers are lightweight, fast, and commonly used on servers or minimal Linux installations.
